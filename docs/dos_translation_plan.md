# Wizardry 7 DOS 한국어 번역 전환 기록

## 기준판

전체화면과 정수배 확대가 가능한 GOG 동봉 DOS판을 주 대상판으로 사용한다.
Gold판용 WinMM 출력 실험과 번역 자료는 폐기하지 않고 비교·재사용 자료로
보존한다.

## 확인된 데이터 호환성

- `NEWGAME.DBS`는 Gold의 `NEWGAME.GLD`와 바이트 단위로 동일하다.
- `SCENARIO.DBS`는 Gold와 같은 368,320바이트 구조이며 아이템 600행과
  몬스터명 1,000행을 기존 도구로 그대로 추출할 수 있다.
- DOS `MSG.HDR` 항목은 `<u16 시작 ID, u16 뱅크 오프셋, u8 ID 범위,
  u8 뱅크>`의 6바이트 구조다. Gold는 마지막 뱅크가 `u16`인 7바이트 구조다.
- DOS `MSG.DBS` 레코드는 `MISC.HDR`의 signed-int16 Huffman 트리로 압축되어
  있다. 각 레코드의 압축 페이로드 첫 바이트는 복원할 바이트 수다.
- Huffman 복원 후 Gold와 DOS는 11,016개 메시지가 같은 ID와 원문을 공유한다.
  ID 25042~25044만 문장 분할이 다르며 DOS에 메시지 하나가 더 있다.

## 구현 상태

- 헤더 형식 자동 판별: 완료
- DOS Huffman 복호화와 CSV 추출: 완료
- Gold/DOS 공용 시나리오 CSV 추출: 완료
- 번역 CSV를 DOS 레코드에 맞춰 Huffman 재압축: 구현 및 소규모 실데이터 검증 완료
- 한글 음절을 기존 Huffman 알파벳만으로 표현하는 가역 3바이트 코드와
  `korean_codebook.json` 생성: 구현 완료
- 2바이트 한글 디코더와 DOS VGA 글꼴 출력 패치: 미구현

## 다음 순서

1. Gold 번역 CSV를 메시지 ID·원문 일치 기준으로 DOS 데이터에 적용한다.
2. 실제 전체 번역으로 256 KiB 뱅크 한도와 레코드당 255바이트 한도를 검증한다.
3. DOS 실행 파일에서 텍스트 제어 처리와 VBFONT 출력 루틴을 찾아
   `ESC + 2바이트` 한글 코드를 글꼴 타일로 변환한다.
4. DOSBox 전체화면에서 메뉴·전투·대화·캐릭터 생성 화면을 검증한다.

## 번역 용어 기준

Google Sheet `Messages!H34:H41`과 `Glossary!A27:D34`의 능력치 약칭은
`근력, 지능, 신앙, 체력, 민첩, 속도, 지각, 업보`로 통일했다. 한 글자
약칭은 인게임에서 의미를 알아보기 어려워 사용하지 않는다.
